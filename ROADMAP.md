# 🧭 Roadmap

> The full, current version is a page:
> **[octagon-religious-research-group-org.github.io/changelog-astro-public/roadmap](https://octagon-religious-research-group-org.github.io/changelog-astro-public/roadmap)**.

This repository is ORG's entry portal on GitHub and the home of the arrival kit every ORG page loads.
This is where it's headed, in rough order. There are no dates: each step happens when it's ready,
and lands in the changelog first.

## Next

- **The new builds and orgspirituality.org, together.** ORG's new builds (this portal, the
  AstroLog, the drasticstatic ORG lab and its dApp preview) began with Renan T's design proposal.
  The open question is how they come together with orgspirituality.org; the likely direction is a
  new, web3-ready site rather than adding web3 onto the current one.
  [Help decide](https://octagon-religious-research-group-org.github.io/changelog-astro-public/three-directions#what-comes-next).
- **Give from a crypto wallet** on [`/donate/`](https://octagon-religious-research-group-org.github.io/donate/):
  the Connect button is there now, as a preview; giving opens once ORG designates a treasury address
  of its own. The [pledge of support](https://octagon-religious-research-group-org.github.io/pledge/)
  already uses the same connection.
- **An ORG help desk** for questions and website feedback, with Telegram built in. Until then,
  feedback goes through ORG's public chat on Telegram and the addresses in the Reach out window.

## Stewardship and succession

So these pages outlive any one person (today drasticstatic, Christopher W, owns or administers the
organization and holds the tokens that publish it):

- [ ] At least two owners for the GitHub organization, from ORG's own people
- [ ] Publishing through org-owned automation (a GitHub App, or an org bot account), not personal tokens
- [ ] A token register, a renewal runbook, and written hand-over steps
- [ ] Exports and backups of the repositories and anything outside GitHub, on a schedule
- [ ] Wallet connect: ORG's own Reown project (a one-line `org.js` change, `give.reownProjectId`), before any treasury address is published

## Later, and still being explored

- **A welcome from Tripp.** The welcome guide keeps a space for a few words from ORG's founder,
  empty on purpose until he'd like to write them.
- **A network of our own.** A small social network ORG's members own, on open protocols like Lens
  and Farcaster, paired with a DAO where members propose and vote. Privacy first. A direction, not
  a promise.
